Build from source

This is an open-source student project — pre-built binaries are published to GitHub Releases as they become available. Until then (or if you'd rather build it yourself), it takes about a minute:

git clone https://github.com/YelloMush/Autonomous_Firewall.git
cd Autonomous_Firewall/desktop_client
npm install
npm run dist   # produces the installer for your current OS in release/

Running npm run dev instead launches the app directly against your local Python backend, without packaging an installer — handy for development.
